# Evidências de I00-08

Validação local em 11/11/2026 com Windows x64, Python 3.12.12 e uv 0.9.26.
A entrega segue TS-ADR-091, TS-ADR-097 e TS-ADR-098. A API publica os modelos
versionados de resposta em `/openapi.json`.

| Verificação | Resultado local |
|---|---|
| `uv sync --locked` | 57 pacotes conferidos. |
| `uv run --no-sync ruff check src infrastructure apps tests` | Sem violações. |
| `uv run --no-sync ruff format --check src infrastructure apps tests` | 38 arquivos formatados. |
| `uv run --no-sync mypy` | Sem erros em 38 arquivos-fonte. |
| `uv run --no-sync pytest` | 42 testes passaram. Dez testes PostgreSQL foram pulados no Windows sem instância local. |
| Requisições HTTP ao Uvicorn em `127.0.0.1` sem configuração do banco | `/health` e `/info` retornaram 200. `/readiness` retornou 503. |
| `uv build --no-sources` | Wheel e distribuição fonte gerados. |

Os testes da API verificam a resposta à ausência de configuração, a falha
real de conexão por uma porta local sem serviço e as rotas declaradas no
OpenAPI. O teste PostgreSQL do CI verifica `503` com o banco em `base`,
`200` após `upgrade head` e `503` novamente após voltar à revisão `0003`.
